# 홈앤쇼핑 월별 직급별 교육 현황 대시보드

Streamlit을 사용한 교육 현황 관리 대시보드입니다.

## 기능

- **월별 필터링**: 특정 월의 교육 현황 조회
- **직급별 필터링**: 임원급, 관리직, 일반직 선택 가능
- **KPI 메트릭**: 전체 대상 인원, 총 이수자, 총 미이수자, 평균 완료율
- **상세 데이터 테이블**: 미이수자 현황 강조 표시
- **직급별 이수 현황**: 원형 그래프로 시각화
- **월별 완료율 추이**: 라인 차트로 경향 분석

## 설치 및 실행

### 요구사항
- Python 3.8+

### 설치
```bash
pip install -r requirements.txt
```

### 실행
```bash
streamlit run app.py
```

## 파일 구조
- `app.py`: Streamlit 메인 애플리케이션
- `ethics_training_data.csv`: 교육 현황 데이터
- `requirements.txt`: 의존성 패키지 목록
